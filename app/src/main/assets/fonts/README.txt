Poster fonts (optional, but they make the posters look like the original tool).

Put these two files in this folder:
  Tajawal-Medium.ttf
  Tajawal-ExtraBold.ttf

Tajawal is an open font (SIL Open Font License). They are the same weights the original
kady-marketing.html loaded (500 and 800). If a file is missing the poster is still drawn,
with the system font, so the build and the app never depend on them.
